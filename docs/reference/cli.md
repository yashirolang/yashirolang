# `{{cc}}` リファレンス

```
{{cc}} [オプション] <入力{{ext}}>
```

コンパイルするのは**入口のファイル 1 つだけ**です。`import` は自動でたどられます。

```bash
{{cc}} hello{{ext}} -o hello
```

---

## 出力

| オプション | 説明 |
|---|---|
| `-o <file>` | 出力する実行ファイル名（既定 `a.out`）。Windows では `.` を含まない名前に `.exe` を足す |
| `-c` | リンクせずオブジェクト（`.o`）を出す |
| `-I <dir>` | `import` を探す場所を足す（何度でも書ける。`-Ideps` の形も可）。パッケージマネージャ [`{{pm}}`](pkg.md) が `deps/` を渡すのに使います |
| `-j <N>` | `clang` を同時に何本走らせるか（既定はコア数、`-j1` で逐次）。⚠️ **出来上がる実行ファイルは並列度で変わりません** |
| `-S` | LLVM IR を標準出力に書いて終了 |
| `--keep-ll` | 実行ファイルを作った後も `.ll` を残す |
| `-O0` / `-O1` / `-O2` / `-O3` | clang に渡す最適化レベル（既定 `-O0`） |
| `--target=<triple>` | 生成する IR の target triple（例 `--target=riscv64-unknown-elf`） |

### `-I` と探索の順番

`import x` を探す場所は 3 つです。

1. 入口ファイルのあるディレクトリ
2. `-I` で足したディレクトリ（書いた順）
3. 標準ライブラリ（`lib/`）

**優先順位はありません。** 2 つ以上の場所で見つかったらエラーにします。
どちらを先にしても「黙って隠れる」ものが出るからです。

## 検査だけする

| オプション | 説明 |
|---|---|
| `--check` | 型検査までで止める。問題が無ければ**何も出さない**（終了コードで判定） |

## 安全性の検査

**既定はすべて警告です。** 段階的に直せるようにこうしてあります。
新しく書くコードでは 3 つとも付けることをおすすめします。

| オプション | 説明 |
|---|---|
| `--deny-move` | 移動済みの値の使用をエラーにする（`E-MOVE-1`） |
| `--deny-borrow` | 借用した値の保存・返却をエラーにする（`E-BORROW-*`） |
| `--deny-mut` | 読み取り専用の借用への書き換えをエラーにする（`E-MUT-1`） |
| `--deny-store-borrow` | 借りものを所有スロットへ入れる箇所をエラーにする（`E-BORROW-7`）。⚠️ **`--deny-borrow` には含まれません** — コンパイラ自身にまだ 40 件残っているためです（[ロードマップ §1.5.1](../roadmap.md#151-いちばん大きな穴--既定で解放しない)） |
| `--drop` | スコープの出口に解放を挿入する |
| `--explain-mut` | 呼び出しで書き換えられる実引数を一覧表示して終了 |

```bash
{{cc}} --deny-move --deny-borrow --deny-mut app{{ext}} -o app
```

⚠️ **`spawn` を使ったファイルでは、上の 3 つが自動で有効になります**（`--deny-store-borrow` は含みません）。
既定が警告のままだと「データ競合が無い」という保証も警告どまりになるためです。
`spawn` は新機能なので、この昇格で壊れる既存コードはありません。

なお、スレッドに渡せるかどうかの検査（`E-SEND-1`〜`3`）は**常にエラー**で、
外すオプションはありません。

## 情報

| オプション | 説明 |
|---|---|
| `--version` | 版番号・stage・target triple |
| `--print-lib-dir` | 標準ライブラリの場所を表示（パッケージマネージャ [`{{pm}}`](pkg.md) が名前の衝突を確かめるのに使います） |
| `-h`, `--help` | 使い方 |

## 処理系を追う

| オプション | 説明 |
|---|---|
| `--dump-tokens` | トークン列を表示して終了 |
| `--dump-ast` | AST を S 式で表示して終了 |

`--dump-tokens` と `--dump-ast` は**入口のファイルだけ**を見ます（`import` をたどりません）。

## 環境変数

| 変数 | 用途 |
|---|---|
| `PLC_CLANG` | 使う clang（`clang-18` など名前が違うとき） |
| `PLC_RUNTIME_O` | ランタイム（`runtime.a`）の場所 |
| `PLC_LIB_DIR` | 標準ライブラリ（`*{{ext}}`）の場所 |
| `PLC_TARGET_TRIPLE` | 既定の target triple |
| `PLC_CFLAGS` | `-c` のときに clang へ追加で渡す引数 |

**どれも埋め込みの既定値より優先されます。** 既定では、コンパイラは自分の実行ファイルからの
相対（`<exe>/../lib/plc/`）でランタイムと標準ライブラリを探すので、
インストール先がどこでも動きます。

---

## 終了コード

| 値 | 意味 |
|---|---|
| 0 | 成功 |
| 1 | コンパイルエラー、または clang の失敗 |

コンパイルしたプログラムの終了コードは、`main` の戻り値の**下位 8 ビット**です
（`return -1` は 255 になります。どの OS でも同じ結果になるよう、生成側で切り詰めています）。
