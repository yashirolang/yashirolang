# ロードマップ

**いま何ができて、何ができないか。これから何を入れるか。**
版ごとの変更は [changelog.md](changelog.md) に、過去の検討の経緯は git の履歴にあります。

---

## 0. 譲らないこと

**目標は「安全な言語仕様」です。ただし Python の書きやすさを採用する。**
この 2 つは衝突するので、次の順で決めます。

### ① 書きやすさが下がるなら、その安全機能は入れない

| 入れないもの | なぜ |
|---|---|
| ライフタイム注釈（`'a`） | 型注釈以外の注釈を増やさない。借用は「呼び出しより長生きしない」規則で代用する |
| 呼び出し側の印（`&x` / `x.clone()`） | 呼ぶたびに書かせない。`own` / `mut` は**定義側に 1 回**だけ |
| 明示的な型引数（`f::<int>(x)`） | 実引数から推論する。書けないなら**その機能を入れない** |
| 検査を通すためだけの書き換え | 「コンパイラを黙らせる作法」を覚えさせない |

### ② 安全性が下がるなら、その書きやすさは入れない

| 入れないもの | なぜ |
|---|---|
| 暗黙の型変換 | `int` と `float` すら混ぜない。どこで精度が落ちたか追えなくなる |
| `null` を返す標準関数 | 「無い」は `T \| None` で型に出す |
| 例外の暗黙伝播 | `raises` に書いていないものは投げられない。握りつぶせない |
| truthiness（`if xs:`） | 「空か」と「None か」を取り違える |

### ③ 両立できないときは、書きやすい側を採って、安全性は別の手段で取り戻す

| 場面 | 採った書きやすさ | 取り戻した安全性 |
|---|---|---|
| ジェネリクス | 型制約を書かせない | 実体化したときに検査し、**発端の行**を示す |
| インタフェース | クラス→インタフェースの変換を書かせない | vtable をオブジェクトに埋め、変換自体を無くす |
| データ競合 | `Send` / `Sync` を書かせない | 所有権検査が既に持つ情報（借り／所有／`rc`）だけで判定する |
| `float` | `1.5` と書ける | `int` との混在は**必ずエラー**にする |

## 1. 現在地

### 動くもの

| 分類 | 内容 |
|---|---|
| 型 | `int` / `float` / `bool` / `str` / `None` / `list[T]` / タプル / `class`（**ジェネリック可**）/ `interface` / **`enum`（中身を持つ枝あり）** / `T \| None` / `rc[T]` / `ptr[T]` / `fn(…) -> T` / 範囲型 |
| 式 | 算術・比較・論理（短絡）・ビット演算・添字・スライス・フィールド・メソッド・三項演算子・`in`・f-string・内包表記・演算子の多重定義・既定引数とキーワード引数・**`lambda`（捕獲あり）** |
| 文 | 宣言・代入・累算代入・`if` / `while` / `for`（`range` / `enumerate`）・**`match` / `case`**・`break` / `continue`・`return`・`pass`・`assert`・`scope:`・`unsafe:` |
| 安全性 | 所有権（`own`）・借用・可変性（`mut`）・解放（`drop`）・共有（`rc[T]`）・範囲型・契約（`requires` / `ensures`） |
| 並行 | `spawn` / `join` / `mutex[T]` / `scope:` と、送出可能性の検査（`E-SEND-1`〜`4`） |
| エラー処理 | `raises` / `try` / `except` / `raise`（アンワインドなし。戻り値検査） |
| 低レベル | `unsafe:` ブロック・生ポインタ・volatile 読み書き・インライン `asm`・`extern`（C のライブラリを呼ぶ） |
| 標準ライブラリ | 文字列・入出力・`dict` / `set` / `json` / `time` / 数値計算（`math` / `linalg` / `stats` / `random` / `complex` / `fft` / `physics`）・作図・表・`decimal` / `bytes`・ソケットと HTTP と **TLS**。**すべて yashirolang で記述** |
| TLS | `https` で取りに行く・待ち受ける。証明書の検証と名前の照合は**外せません**。注意: **既定のビルドには入りません**（`make TLS=1`。中身は OpenSSL 3 に任せます） |
| 道具 | パッケージマネージャ `ysm`（レジストリ無し・git 直指し・MVS・ロック）／デバッグ情報（`-g`）／証明（`--prove-report`） |

### 処理系

| | |
|---|---|
| 実装 | C 版（stage0）と yashirolang 版（stage1 以降） |
| バックエンド | LLVM IR のテキストを出力し、アセンブル・リンクは clang に委譲 |
| セルフホスト | **到達済み** — stage2 と stage3 がバイト単位で一致（不動点） |
| 検証 | テスト **629 件** ＋ 2 実装の出力一致 ＋ AddressSanitizer 19 件 ＋ `ysm` 31 件 ＋ 不動点（`make test`） |
| 対応環境 | Linux / macOS（Intel・Apple Silicon）/ Windows（MSYS2）/ RISC-V ベアメタル |

### 安全性として保証していること

| 保証 | どう保証するか |
|---|---|
| null 参照が無い | `T \| None` と絞り込み |
| 未初期化の読み出しが無い | 宣言に初期化式が必須。フィールドは `init` の**どの経路でも代入するか**を検査 |
| 範囲外アクセスで壊れない | 実行時に検査して停止（**外す手段はありません**） |
| 型の取り違えが無い | 静的型付け・暗黙変換なし |
| 握りつぶされたエラーが無い | `raises` は `try` か再宣言のどちらかを強制 |
| 二重解放・解放後の使用が無い | 所有権・借用・可変性の検査（**既定でエラー**。逃げ道は `--warn-own`） |
| データ競合が無い | `spawn` に渡せるのは `own` した値・`mutex[T]`・`scope:` の中の借りだけ |
| 整数があふれない | `+` `-` `*` `**` と単項 `-`、`int(…)` を常に検査（折り返しは `wrap_*`） |
| 0 で割れない | 整数も `float` も実行時エラー（無限大が要るときは `math.inf()`） |
| 値の範囲を型で縛れる | `type Percent = int range(0, 100)`（外すオプションはありません） |
| 事前・事後条件を書ける | `requires` / `ensures` |
| 場合分けに漏れが無い | `enum` の `match` は**枝が 1 つでも欠けるとエラー**（`int` / `str` は `case _` が必須） |

Rust・Ada と並べた比較表は [README](../README.md#rustada-と比べたときの立ち位置) にあります。

### 保証していないこと

- `unsafe:` の中身（生ポインタ・`asm`）
- `--no-overflow-check` を付けたとき（桁あふれの検査が出ません。注意: 添字の検査は残ります）
- `--warn-own` を付けたとき（所有権の指摘が警告になります。**このコードは保証の外です**）
- `rc[T]` の循環参照（解放されません。弱参照はまだありません）
- SPARK のような**証明**。区間解析で「必ず成り立つ」検査を消すところまでです（SMT ソルバは入れません）
- **TLS の暗号そのもの**。`lib/tls.ys` が保証するのは「危険な使い方を書けないこと」だけで、ハンドシェイクと証明書の検証は OpenSSL 3 のものです（[design/tls.md](design/tls.md)）

### 書きやすさの現在地

同じ処理（CSV を読む → 集計 → 図を 2 枚 → 報告）で **Python の約 1.7 倍の行数**です
（`examples/sales_report.ys` と pandas + matplotlib の比較で 52 行 対 30 行）。
差の内訳は型注釈（15 か所）と、下の「これから」に並ぶ機能です。

## 2. これから

### 言語に足すもの（優先順）

| 順 | 足すもの | なぜ要るか |
|---|---|---|
| — | （言語に足す予定のものは、いまありません） | 次に足すかどうかは、書いていて足りないと分かったときに決めます |

注意: **文字列の書式指定は 0.37.0 で入りました**（A-45）。`f"{x:>8}"` / `f"{v:.2f}"`。
桁は表示幅で数えます（全角は 2 桁）。

注意: **複製の抽象は 0.37.0 で入りました**（A-44）。`copy(v)` が `list` / クラス
（`__copy__` を書いたもの）／中身を持つ列挙まで通ります。値型は呼び出しを出しません。

注意: **捕獲（クロージャ）は 0.36.0 で入りました**（A-43）。捕まえた値は**枠の上**に
置くので、確保も参照カウントも要りません。代わりに**逃がせません**（返す・しまう・
`spawn` に渡す、はコンパイル時に断ります）。捕まえられるのは値型だけです。
残りは [design/closures.md](design/closures.md) §5 にまとめました——`str` / `list` の
捕獲と、捕獲した lambda を**しまえる**ようにする話（表現を変えることになります）。

注意: **中身を持つ枝は 0.35.0 で入りました**（A-41）。枝ごとの隠しクラスに
先頭タグを置く形です（[design/enum-payload.md](design/enum-payload.md)）。入れ子の
パターンとガードは入れていません。

注意: **インタフェース越しの `raises` は 0.34.0 で入りました**（A-40）。投げうるエラーは
宣言で固定します（実装に同じ `raises` を求めます）。**関数型（`fn(...)`）は据え置き**で、
`raises` する関数は値にできません——型に `raises` を書く欄が無いためです。

注意: **反復の抽象は 0.32.0 で入りました**（A-39）。`__first__` / `__next__` / `__get__`
（カーソルは `int`）を持つクラスは `for` で回せます。`dict` と `set` にも付けたので、
**読み取り専用の借用のまま回せます**——`d.keys()` は詰め直しのために `mut self` が
要るので、「読むだけの関数」からは回せませんでした。

### 直しておくもの（負債）

| 直すもの | なぜ |
|---|---|
| **インタフェース実装の引数名を検査していない** | `check_implements` は型と戻り型しか比べません。宣言が `def area(self, k: int)`、実装が `def area(self, n: int)` でも通ります。0.31.0 で**インタフェース越しだけキーワード引数を使えない**という非対称を作ったので、そこを開けるなら**先に名前一致を必須に**します |

注意: **既定引数とキーワード引数は 0.31.0 で入りました**（A-38）。既定値に書けるのは
**リテラルだけ**です——`def f(xs=[])` のような「呼び出しをまたいで共有される既定値」を
書けなくするためです（list が要るときは `xs: list[int] | None = None`）。
可変長引数（`*args` / `**kwargs`）は**入れません**。呼び先の引数がソースから
決まらなくなります。

注意: **`enum` の枝はまだ中身を持ちません**（0.30.0）。`Shape.Circle(r)` のような
代数的データ型は、枝に中身を足しても既存のコードが壊れない形にしてあります。
構文木はいまもクラスとインタフェースで書けるので、必要が出てからにします。

### ライブラリに足すもの

| 足すもの | なぜ要るか |
|---|---|
| **正規表現** | ログ処理・入力検証 |
| **日付時刻** | `time` はいま単調時計と実時刻だけです |
| **クライアント側の keep-alive** | `http` は 1 要求ごとに繋ぎ直します |

**ライブラリは言語を 1 行も変えずに足せます**（`json` / `set` / `decimal` がその実例です）。

### 処理系に足すもの

| 足すもの | 中身 |
|---|---|
| **整形器**（`gofmt` 相当） | インデントが意味を持つ言語で整形器が無いと、書き手が増えたときに差分が揺れます。いま `tools/` にあるのは改名と命名検査だけです |
| **単体テストの仕組み** | コンパイラ自身はケースで固めていますが、**利用者のプロジェクトには `assert` しかありません**（`ysm test` に当たるものが無い） |
| **yashirolang 側のカバレッジ計測** | `selfhost/` と `lib/` の実行が測れていません（C 版は `make coverage` で測れます） |
| **道具のための機械可読な出力**（A-36） | 診断を JSON で出す／`--dump-ast` の安定した形。エディタ連携のため |
| **GPU**（A-19） | `gpu:` ブロックの中だけ SPIR-V / PTX へ出す案。注意: 先にベクトル化の残りを片付けます |
| **組み込み・OS 向け**（A-20） | 割り込みハンドラの属性・リンカスクリプトの同梱・ヒープ無しモード（`--no-heap`）・`mmio[T]`・スタック使用量の静的な上限 |

注意: **ヒープ無しモードは言語の意味を変えます**（`append` が失敗しうる）。入れるならモードを分け、既定の書き味は変えません。

| リポジトリ | 中身 |
|---|---|
| `yashirolang`（ここ） | `-g` の DWARF・診断・`--dump-tokens` / `--dump-ast` |
| [yashirolang-IDE](https://github.com/yashirolang/yashirolang-IDE) | Arduino 風の最小 IDE。コンパイラを**外から呼ぶだけ** |

## 3. 入れないと決めたもの

| 入れないもの | 理由 |
|---|---|
| `async` / `await` | スレッドと `scope:` で足ります。あとから**利用者のコードを変えずに**非同期を得る道を残してあります（[design/concurrency.md](design/concurrency.md) §6） |
| アンワインドする例外 | カーネルで使えなくなります。`raises` は戻り値検査に落ちます |
| `Send` / `Sync` に相当するトレイト | 所有権検査が持つ情報だけで判定できます。書くものを増やしません |
| `from x import y` / `import … as …` | 名前の出どころがソースから読み取れなくなります |
| 継承 | インタフェースと合成で足ります |
| SMT ソルバの同梱（SPARK 相当の証明） | 「clang だけで建つ」という約束が壊れます |
| レジストリ（中央のパッケージ置き場） | 運営が要ります。git と `package.lock` で同じ保証を得ます |
| TLS の自前実装 | 「安全な言語」の看板の下で、**いちばん危ない部分だけが未検証**になります（[design/tls.md](design/tls.md)） |
| 証明書の検証を外す口 | 外した状態が本番に残ります。範囲外アクセスの検査に逃げ道を置いていないのと同じ扱いです |
| TLS を既定のビルドに入れること | 「clang だけで建つ」が壊れます。SMT ソルバを同梱しないのと同じ理由です |
